# CRNA-seq Analysis of Human Gene Expression
## Introduction
This project demonstrates a computational RNA-seq workflow using publicly available human RNA-seq data. The workflow covers quality control, read alignment, gene quantification, exploratory analysis, and biological interpretation. The methods demonstrated are directly applicable to transcriptomic studies in cancer genomics.
## Dataset and data source
The RNA-seq dataset used in this project was accessed from Kaggle as the RNA-seq Example Data. The Kaggle dataset provides the chrX_data dataset originally distributed by the Johns Hopkins Center for Computational Biology.

The dataset contains RNA-seq data from human samples generated on the Illumina HiSeq 2500 platform. The dataset is designed to demonstrate an RNA-seq analysis workflow and focuses on sequencing data from the human X chromosome.

The dataset contains raw sequencing reads in FASTQ format, a reference genome sequence in FASTA format, gene annotations in GTF format, HISAT2 alignment indexes, a sample merge list, and phenotypic/sample metadata.

The original dataset can be accessed from the Johns Hopkins repository, while the version used for this project was obtained from Kaggle.
